\# DON'T WAKE HIM



A cooperative Roblox horror game where noise can turn a quiet escape into a chase.



\## About



\*\*DON'T WAKE HIM\*\* is a small multiplayer horror-game project built around stealth, exploration, and teamwork.



Players enter a house, search for keys and clues, manage their noise, avoid waking a sleeping monster, and attempt to escape together.



\### Core Gameplay



\* Explore a compact horror house.

\* Search for objectives and optional clues.

\* Manage noise caused by movement and interactions.

\* Avoid a monster that reacts to disturbances.

\* Use hiding spots and doors strategically.

\* Unlock the exit and try to escape as a team.



\### Project Goals



\* Support small multiplayer sessions.

\* Provide readable, mobile-friendly UI.

\* Keep gameplay decisions server-authoritative.

\* Use cosmetic-first progression rather than pay-to-win mechanics.

\* Improve reliability through repeatable testing.

\## Getting Started



\### Requirements



\* A Roblox account

\* Roblox Studio

\* Git, if cloning this repository



\### Download



Clone the repository:



```bash

git clone https://github.com/YOUR\_USERNAME/DontWakeHim\_Roblox.git

cd DontWakeHim\_Roblox

```



Replace `YOUR\_USERNAME` with the GitHub account that owns the repository.



\### Open the Game



1\. Locate `DontWakeHim.rbxlx` in the downloaded project.

2\. Open it using Roblox Studio.

3\. Review the Output window for errors.

4\. Use Studio's Play or Test tools to run the game.

5\. Test gameplay before publishing or sharing a public experience.



If the place file is absent, check the repository's files or ask the project owner for the correct Roblox place file.
